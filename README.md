# MyFlow 🌿

MyFlow nació como una forma simple de organizar las tareas del día sin convertir la productividad en algo complicado.

Quise crear una aplicación donde fuera fácil ver qué tengo por iniciar, qué estoy haciendo y qué ya terminé, manteniendo lo importante en un solo lugar y con una interfaz clara y amable.

Este proyecto fue desarrollado como parte de mi aprendizaje en desarrollo Front End y me permitió trabajar no solo el diseño de la interfaz, sino también la lógica y el comportamiento de una aplicación real.

## ✨ ¿Qué puedes hacer en MyFlow?

- Crear tareas y definir su prioridad y fecha límite.
- Iniciar una tarea y moverla al estado **En curso**.
- Marcar tareas como **Completadas**.
- Editar y eliminar tareas.
- Buscar tareas por su descripción.
- Filtrar por estado.
- Visualizar estadísticas y el progreso general.
- Recibir ideas mediante la función **Inspírame**.
- Conservar las tareas en el navegador usando `localStorage`.
- Utilizar un formulario de contacto con validación e interacción en la interfaz.

## 💻 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript ES Modules
- LocalStorage
- Consumo de API para la función **Inspírame**
- Git y GitHub

## 🌱 Sobre el diseño

Busqué que MyFlow se sintiera liviano y fácil de entender. La paleta combina violeta y verde agua para dar identidad a la aplicación y ayudar a diferenciar acciones, estados y progreso sin sobrecargar la pantalla.

La interfaz es responsive y está pensada para que las tareas sean siempre las protagonistas.

## 📚 Lo que aprendí

Uno de los principales desafíos fue conectar la lógica de JavaScript con la interfaz: los cambios de estado de cada tarea debían reflejarse inmediatamente en las tarjetas, filtros, estadísticas y porcentaje de progreso.

También trabajé con persistencia de datos en el navegador, fechas límite, búsqueda, filtros, modales, validación de formularios, consumo de una API y diseño responsive.
